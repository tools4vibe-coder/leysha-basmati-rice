# Leysha brand website

Local, dependency-free website. Run `python3 -m http.server 8766 --bind 127.0.0.1` from this folder and open http://127.0.0.1:8766.

This first concept prioritises heritage, brand philosophy and processing before a compact range section. Acquerello informed the story-first approach; no Acquerello assets or proprietary technology claims are used.

Company chronology and processing descriptions were checked against https://ssiel.com/ on 29 October 2026. Product categories, descriptions and pack sizes were checked against https://ssiel.com/leysha-basmati-rice/. The official Nainital paragraph names Utsav, so that contradictory description has deliberately not been reused. Parent-company history is attributed to SSIEL, not to the Leysha brand's founding date.

The philosophical wording is proposed brand copy for client review. No superiority percentages, proprietary machinery, ageing duration or competitor comparisons have been invented. Final publication should confirm brand copy, current packaging and product specifications with the client.

Images: original local Leysha horizontal logo and a vertical lockup extracted as vector artwork from guideline page 13; downloaded Netlify hero film; factory and rice imagery from SSIEL; pack imagery from the supplied Netlify concept. Painted fields are illustrative, not a photograph of the company's farms. Fonts are served locally: original Avigea Regular and Helvetica Regular/Bold/Oblique. No substitute or synthetic Avigea italic is used. Navigation, process accordions, product dialogs and email/phone links work without a backend. Enquiries open the user's email app; no form sends data automatically.


Brand update: follows “New Leysha Brand guidelines 2oth April.pdf”. Leysha red uses the explicit HEX #be2726; off-white uses RGB 255/241/226 (#fff1e2), matching the visible swatch. Page 19 is internally inconsistent: the red RGB line says 198/39/38 while its HEX is #be2726; the off-white HEX line says #ffffff. These discrepancies are documented rather than silently treated as equivalent. SSIEL dark red is #992520.

Original horizontal logo renders at 100px high; mobile uses the guideline's vertical logo at 230px high, with a taller masthead to preserve proportions and breathing room. Mobile masthead scrolls away to leave space for the film reveal. Headlines use Avigea Regular; no original full Italic font file was supplied or found, so italic styling has been removed rather than approximated. English website currently has no Hindi content.

Header refinement: at the user’s explicit request, the website header uses the symbol-only Leysha logo at 130px wide on desktop and 112px on mobile, within a compact 90px / 72px sticky header. This supersedes the full-lockup header sizing described above; the footer retains the full lockup.

Story and technology update: the former process accordion is now an editorial introduction beside three portrait cards, following the supplied layout reference. Heritage and process cards open in-page readers, while the film card plays the existing 45-second brand film in a modal. Processing and pre/post-cook checks are paraphrased from https://ssiel.com/ and https://ssiel.com/ssiel-qc-lab/ (checked 29 October 2026). Lab photography comes from the official SSIEL quality-control page. These readers do not create internal pages; the header destinations remain disabled.

Quality interaction: hover, focus or select a grain characteristic to expand its explanation and crossfade the left panel to related media. The default is the supplied trust seal. Aroma uses a short serving excerpt from the existing brand film; grain length uses SSIEL’s grain close-up; texture uses the existing cooked-rice image. Inactive video pauses. Touch can toggle rows, and Escape restores the seal. No newly generated assets were needed.

Philosophy section now uses the supplied videos/rice grain.mp4 in a centre column between the tagline and supporting copy. The portrait clip is shown uncropped, muted and looping, with a pause/play button and offscreen pause behaviour. Narrow layouts stack heading, film and copy.
